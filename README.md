# GBA Web Player

A GitHub Pages-ready browser player for Game Boy Advance ROMs.

## Run it

1. Enable GitHub Pages for the `main` branch.
2. Open the Pages URL.
3. Choose your `.gba` ROM.
4. The emulator runs the selected file locally in the browser.

The ROM is not uploaded by the webpage.

## Notes

The player uses EmulatorJS and its GBA emulator core from the public EmulatorJS CDN. Internet access is required for the emulator library.
